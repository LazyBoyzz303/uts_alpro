Modul A: Proses Utama

Penanggung jawab: Steve Nathanael Intan

Algoritma deskriptif

  1. Mulai; terima nomor dan nama pelanggan.
  2. Terima meter awal; ulangi sampai berupa angka dan tidak negatif.
  3. Terima meter akhir; ulangi sampai berupa angka dan tidak lebih kecil dari meter awal.
  4. Terima status terlambat; ulangi sampai berisi y atau t.
  5. Hitung pemakaian = meter akhir - meter awal.
  6. Jika pemakaian ≤ 10, seluruhnya ditarif Rp2.500.
  7. Jika 10 < pemakaian ≤ 20, 10 m³ pertama Rp2.500 dan sisanya Rp4.000.
  8. Jika pemakaian > 20, 10 m³ pertama Rp2.500, 10 m³ berikutnya Rp4.000, sisanya Rp6.000.
  9. Jumlahkan menjadi biaya pemakaian.
  10. Jika terlambat, denda = 5% x biaya pemakaian; jika tidak, denda = 0.
  11. Total tagihan = biaya pemakaian + administrasi + denda; tampilkan rincian.

Pseudocode

SELAMA lanjut = 'y' LAKUKAN
   BACA nomorPelanggan, namaPelanggan
   ULANGI BACA meterAwal SAMPAI angka DAN meterAwal >= 0
   ULANGI BACA meterAkhir SAMPAI angka DAN meterAkhir >= meterAwal
   ULANGI BACA terlambat SAMPAI terlambat IN {y,t}
   pemakaian ← meterAkhir - meterAwal
   JIKA pemakaian <= BATAS_1 MAKA
      biayaTingkat1 ← pemakaian x TARIF_1
   LAIN JIKA pemakaian <= BATAS_2 MAKA
      biayaTingkat1 ← BATAS_1 x TARIF_1
      biayaTingkat2 ← (pemakaian - BATAS_1) x TARIF_2
   LAIN
      biayaTingkat1 ← BATAS_1 x TARIF_1
      biayaTingkat2 ← (BATAS_2 - BATAS_1) x TARIF_2
      biayaTingkat3 ← (pemakaian - BATAS_2) x TARIF_3
   biayaPemakaian ← biayaTingkat1 + biayaTingkat2 + biayaTingkat3
   JIKA terlambat MAKA denda ← biayaPemakaian x PERSEN_DENDA / 100
   LAIN denda ← 0
   totalTagihan ← biayaPemakaian + BIAYA_ADMIN + denda
   TAMPILKAN rincian tagihan
AKHIR SELAMA
