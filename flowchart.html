Flowchart

Flowchart disusun untuk Modul A, Modul B, dan program terintegrasi. Alurnya sama dengan pseudocode dan source code.

Keterangan simbol

SimbolArti
OvalMulai / selesai
Jajaran genjangInput / output
Persegi panjangProses atau perhitungan
Belah ketupatKeputusan (percabangan atau pengecekan validasi)

Flowchart Modul A: proses utama

flowchart TD
  A([Mulai]) --> B[/Input nomor, nama/]
  B --> C[/Input meter awal/]
  C --> D{Angka dan >= 0?}
  D -- Tidak --> C
  D -- Ya --> E[/Input meter akhir/]
  E --> F{Angka dan >= meter awal?}
  F -- Tidak --> E
  F -- Ya --> G[/Input status terlambat/]
  G --> H{y atau t?}
  H -- Tidak --> G
  H -- Ya --> I[pemakaian = akhir - awal]
  I --> J{pemakaian <= 10?}
  J -- Ya --> K[tingkat1 = pemakaian x 2500]
  J -- Tidak --> L{pemakaian <= 20?}
  L -- Ya --> M[tingkat1 = 25000
tingkat2 = pemakaian-10 x 4000]
  L -- Tidak --> N[tingkat1 = 25000, tingkat2 = 40000
tingkat3 = pemakaian-20 x 6000]
  K --> O[biayaPemakaian = jumlah tingkat]
  M --> O
  N --> O
  O --> P{Terlambat?}
  P -- Ya --> Q[denda = 5% x biayaPemakaian]
  P -- Tidak --> R[denda = 0]
  Q --> S[total = biaya + admin + denda]
  R --> S
  S --> T[/Tampilkan rincian tagihan/]
  T --> U([Ke Modul B])

Flowchart Modul B: rekapitulasi

flowchart TD
  A([Dari Modul A]) --> B[jumlahPelanggan + 1]
  B --> C{Terlambat?}
  C -- Ya --> D[jumlahTerlambat + 1]
  C -- Tidak --> E
  D --> E[totalPemakaian += pemakaian]
  E --> F{pemakaian > 20?}
  F -- Ya --> G[jumlahDiAtas20 + 1]
  F -- Tidak --> H
  G --> H{pemakaian > tertinggi?}
  H -- Ya --> I[simpan tertinggi dan nama]
  H -- Tidak --> J
  I --> J[totalAdmin, totalDenda, totalPendapatan += nilai]
  J --> K([Selesai Modul B])

Flowchart program terintegrasi

flowchart TD
  A([Mulai]) --> B[Inisialisasi total = 0]
  B --> C[[Modul A: hitung tagihan]]
  C --> D[[Modul B: update rekap]]
  D --> E[/Input lanjut y/t/]
  E --> V{y atau t?}
  V -- Tidak --> E
  V -- Ya --> F{lanjut = y?}
  F -- Ya --> C
  F -- Tidak --> G[Hitung rata-rata]
  G --> H[/Tampilkan rekapitulasi/]
  H --> I([Selesai])
