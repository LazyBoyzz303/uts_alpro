Pernyataan Penggunaan AI

Kelompok menggunakan AI sesuai kebijakan mata kuliah: untuk memahami konsep dan membantu menyusun draf, bukan untuk menyerahkan hasil tanpa pemeriksaan. Seluruh bagian yang dipakai sudah dipelajari dan dapat dijelaskan oleh kedua anggota.

Isian bertanda kuning adalah bagian yang harus kalian sesuaikan sendiri dengan kenyataan, terutama perubahan dan hasil verifikasi.
1. Nama alat AIClaude (Anthropic)
2. Tujuan penggunaanMembantu menyusun draf analisis masalah, algoritma, pseudocode, flowchart, source code C++, dan tabel pengujian untuk Studi Kasus 05, serta menyusun kerangka halaman GitHub Pages.
3. Prompt utama
  • Meminta pembuatan bagian Studi Kasus 05 dari dokumen proyek UTS.
  • Meminta source code dipisah menjadi modul_a.cpp, modul_b.cpp, dan program_final.cpp.
  • Meminta kode HTML untuk halaman GitHub Pages sesuai struktur di dokumen proyek.
  • [Tambahkan prompt lain yang kalian pakai]
4. Bagian jawaban yang digunakan[Contoh: struktur tabel IPO dan variabel, rancangan percabangan tarif progresif, kerangka validasi input, template halaman HTML.]
5. Perubahan yang dilakukan mahasiswa[Contoh: mengganti nama variabel, menambah komentar, mengubah teks pesan error, menambah skenario uji, memperbaiki bagian yang salah.]
6. Hasil verifikasi mahasiswa[Contoh: menjalankan program dengan 11 skenario uji, mencocokkan hasil dengan hitungan manual, mencoba mengubah batas tarif dan menjalankan ulang.]

Penegasan

Kedua anggota memahami seluruh alur program, dapat melakukan trace nilai variabel, dan siap memodifikasi ketentuan saat presentasi.
