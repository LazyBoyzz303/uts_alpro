Modul B: Rekapitulasi

Penanggung jawab: Steve Nathanael Intan

Algoritma deskriptif

  1. Siapkan seluruh penghitung dan total dengan nilai 0; pemakaianTertinggi = 0, pelangganTertinggi = "-".
  2. Untuk setiap pelanggan, tambahkan jumlahPelanggan; jika terlambat, tambahkan jumlahTerlambat.
  3. Tambahkan pemakaian ke totalPemakaian; jika pemakaian > 20, tambahkan jumlahDiAtas20.
  4. Jika pemakaian > pemakaianTertinggi, simpan pemakaian dan nama pelanggannya.
  5. Tambahkan administrasi, denda, dan total tagihan ke total masing-masing.
  6. Setelah perulangan selesai, hitung rata-rata jika jumlahPelanggan > 0, lalu tampilkan rekapitulasi.

Pseudocode

jumlahPelanggan ← jumlahPelanggan + 1
JIKA terlambat MAKA jumlahTerlambat ← jumlahTerlambat + 1
totalPemakaian ← totalPemakaian + pemakaian
JIKA pemakaian > 20 MAKA jumlahDiAtas20 ← jumlahDiAtas20 + 1
JIKA pemakaian > pemakaianTertinggi MAKA
   pemakaianTertinggi ← pemakaian
   pelangganTertinggi ← namaPelanggan
totalAdmin ← totalAdmin + BIAYA_ADMIN
totalDenda ← totalDenda + denda
totalPendapatan ← totalPendapatan + totalTagihan
...
JIKA jumlahPelanggan > 0 MAKA rataRata ← totalPemakaian / jumlahPelanggan
TAMPILKAN rekapitulasi

  C -- Tidak --> E
  D --> E[totalPemakaian += pemakaian]
  E --> F{pemakaian > 20?}
  F -- Ya --> G[jumlahDiAtas20 + 1]
  F -- Tidak --> H
  G --> H{pemakaian > tertinggi?}
  H -- Ya --> I[simpan tertinggi dan nama]
  H -- Tidak --> J
  I --> J[totalAdmin, totalDenda, totalPendapatan += nilai]
  J --> K([Selesai Modul B])
